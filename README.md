# Pea gravel and landscaping aggregate density data

Open data behind the calculators at
[peagravelcalculators.com](https://peagravelcalculators.com).

**Canonical version, with the tables rendered and the full methodology:

Most gravel calculators pick a density silently and never publish it. That is why
two calculators give different answers for the same job. These are the figures
this project uses, stated openly so anyone can check them or disagree with them.

## The headline figure

Pea gravel is taken as **100 lb per cubic foot**, which is **1.35 US tons per
cubic yard** or **1,602 kg per cubic metre**, for dry, loose, washed 3/8 inch
material.

Published figures for the same material range from **1.21 to 1.42 US tons per
cubic yard**, a spread of about 17 percent. On a 3 cubic yard order that is the
difference between 3.6 and 4.3 tons. This project uses the mid point and says so.

## Caveats worth reading

- Bulk density varies by quarry, parent stone, stone size and moisture. Your
  supplier's figure beats any published one.
- Wet material runs roughly 8 percent heavier. Quarries quote dry weight.
- These are loose, uncompacted figures. Compacted material is denser.
- Lava rock is genuinely about half the weight of pea gravel because it is a
  vesicular volcanic aggregate. Landscape sites often list it near 100 lb/ft3,
  which is wrong.
